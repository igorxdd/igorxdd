# Olá, eu sou o Igor 👋

### Estou construindo minha carreira em Quality Assurance e automação de testes.

Gosto de entender como um produto funciona, explorar cenários e encontrar maneiras de torná-lo mais confiável para quem o utiliza. Para mim, qualidade vai além de encontrar bugs: envolve prevenir problemas, comunicar riscos com clareza e colaborar para entregar uma experiência melhor.

Hoje, concentro meus estudos e projetos práticos em **automação de testes Web e de APIs**. Utilizo **Playwright com TypeScript**, **Cypress com JavaScript** e **REST Assured com Java**, além do **Postman** para explorar, validar e documentar APIs. Tenho buscado escrever testes legíveis, reutilizáveis e fáceis de manter, aplicando padrões utilizados no dia a dia de times de tecnologia.

## O que estou desenvolvendo

- Automação de testes funcionais e end-to-end
- Testes de API com REST Assured e Postman
- Estruturação de projetos com Page Object Model
- Criação de fixtures e componentes reutilizáveis
- Automação Web com Playwright e Cypress
- Boas práticas com Git, TypeScript, JavaScript e Java
- Relatórios de execução e testes em diferentes navegadores
- Organização de código pensando em manutenção e escalabilidade
